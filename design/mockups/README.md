# Mockups — reference only, never shipped

Design explorations. Nothing here is a route, is built, or is served: these files live outside
`apps/web`, so the Next.js route table and `tsconfig` never see them.

Read them as pictures of an idea. The content inside is **invented** — sample questions, sample marks,
sample progress — which is exactly why it may not sit in the app (PRINCIPLES §29, no mock intelligence in
production paths).

| File | What it is |
|---|---|
| `senior-studio.tsx` | Moved out of `apps/web/src/app/demo/` on 25 Oct 2026. A 1,325-line studio layout with three theme presets named after other products (ALLEN Overseas, Bhanzu, SaveMyExams) and invented sample content for Maths and Sociology. It was reachable as `/demo` by any signed-in account. Kept for the layout ideas; the names and the sample data do not come back into the product. |

If an idea here earns its place, it returns as real pages reading real data — like the pacing bar and the
stepped worked examples did (`docs/STUDENT-APP.md` §12), not by being linked back into the app.
